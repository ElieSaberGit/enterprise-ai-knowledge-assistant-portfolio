# Enterprise AI Knowledge Assistant Portfolio Instructions

## Company Standards

Keep portfolio claims synchronized with verified evidence from the private
implementation and the sibling `company-golden-foundation-private` repository.

## Method Documentation

If code is introduced, every authored method and constructor must include a
concise comment above its declaration explaining its business purpose, workflow
role, architectural boundary, important constraint, side effect, or non-obvious
behavior.

- Use XML documentation for public and protected declarations.
- Use XML documentation or a focused preceding comment for private declarations.
- Do not write comments that merely translate the code into English.

## Evidence Rule

Do not present an experimental or in-progress learning slice as a completed,
production-ready product capability.
